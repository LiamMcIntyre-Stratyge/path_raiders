- `export function isWalkable(r: number, c: number, base: TerrainType[][], over: OverlayType[][]): boolean`
  - returns false when overlay is 'wall' | 'break_mach' | 'break_plant' | 'break_wiz'

  - returns true when overlay is 'base_zone'
